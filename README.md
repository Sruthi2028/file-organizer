# Command Line File Organizer (C)

This project is a command-line utility written in C that automatically organizes files into folders based on file extensions.

## Features
- Scans directory files
- Detects file extensions
- Creates folders automatically
- Moves files to correct folders

## Technologies
- C Programming
- File System Operations
- Directory Traversal

## Example

Before:
photo.png
report.pdf
notes.txt

After:
Images/photo.png
Documents/report.pdf
Text/notes.txt
